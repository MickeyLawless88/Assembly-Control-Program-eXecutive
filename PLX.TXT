PL/X  -  ACPX STARTUP SCRIPT LANGUAGE (draft 2)
Language designed by Mickey W. Lawless.  Interpreter: plx.c (C89).

USAGE
  acpx                    loads ACP.PLX from the current directory if present
  acpx -c FILE.PLX        load FILE.PLX (a bare FILE.PLX argument also works)
  acpx -n                 ignore scripts, use the built-in banner
  plxcfg                  interactive menu (wizard / check / run / call)
  plxcfg new|check|run FILE.PLX      plxcfg call FILE.PLX BLOCK
  plxcfg lines FILE.PLX [DIGITS [Z|P]]   editor line numbers: 1 / 01 / 00001
A script that fails to load or errors at run time prints PLX ERROR LINE n
and acpx falls back to the built-in banner.  HALT / input EOF ends acpx.

LEXICAL
  *NAME*            label (at statement start); also the target of GOTO/PROCEED/RET
  "text" 'text'     strings; escapes \n \r \t \e(ESC) \a \f \xHH \\ \" \'
                    ('\n' is just a one-character string)
  123  $1F           decimal / hex numbers
  & at line start   joins the line to the previous statement (or & at line end)
  /* .. */  // ..   comments
  names are case-insensitive, 15 significant characters
  .EQ. .NE. .LT. .GT. .LE. .GE. .AND. .OR. .NOT.   dotted operators

STATEMENTS (one per line, several allowed per line where unambiguous)
  [ items ]                    prompt list: "text" prints; NAME:fmt READS a line
  items                        output list, e.g.  "HELLO ",NAME,'\n'
  NAME=[ items ]               print the items AND store the text in NAME
  ASSIGN [INT|STR] NAME.EQ.expr     also:  NAME = expr   NAME.EQ.expr
  IF (expr) [THEN] stmt [ELSE stmt]     stmt may be a { block }
  GOTO *L*   PROCEED *L*   RET *L*      jump to label (PROCEED/RET alone = no-op)
  CALL NAME                    run block NAME
  HALT [items]  /  EXIT        print optional items, end the program
  DELAY ms     BEEP     PAUSE [items]  (PAUSE waits for RETURN)
  END(NAME)  NAME<END>         optional closing markers inside a block (ignored)

BLOCKS
  NAME { ... }      only BANNER runs where it appears in the script
  VAR(NAME) { }     hoisted: runs BEFORE the script, so declarations may sit anywhere
  SUB NAME { }      or any other name: callable (CALL NAME) and used as host hooks
  Host hooks:  MENUHDR  printed above every ACP menu (replaces the built-in header)
               GOODBYE  runs on BYE / option 5 (replaces "SIGNED OFF.")

EXPRESSIONS  (lowest to highest)  .OR.  .AND.  .NOT.  comparison  + -  * /
  == <> != < > <= >= =  .EQ. .NE. ..   strings compare as text, numbers numerically
  '+' and '.AND.' CONCATENATE if either side is a string (DATE.EQ.MON.AND.DAY works)
  variables are INT or string; ASSIGN INT / ASSIGN STR force the type

FORMATS (after a colon, or bare in an output list)
  A  text, upcased on input     S  text as typed     I  integer     Z  zero-padded
  H  hidden input (echo off on Unix; shows one X per character)
  nA1 = n x A1 = A<n>.  "5A1" reads at most 5 characters.  "I4" prints right-justified.
  NAME:fmt in [ ] reads; NAME:fmt elsewhere prints.  Bare I4 / A10 in an output
  list prints USRNO, then PORTNO (per block run), blank if undefined.
  On a terminal the newline you type is echoed, so a '\n' item right after a
  visible input is dropped (no blank line); with piped input it is kept.

PREDEFINED VARIABLES
  VERSION (acpx version)  SYSMON (OCT)  SYSDAY  SYSYEAR  SYSDATE (MM/DD/YY)  SYSTIME
  LNWIDTH  editor line-number digits, 1-9 (default 5, blank padded: "    1")
  LNZERO   1 = zero-pad the editor line numbers: LNWIDTH 2 -> 01, 5 -> 00001
           (set with: plxcfg lines FILE.PLX [DIGITS [Z|P]], the wizard, or menu 5;
           they live in a VAR(LINENUM) block, which plxcfg rewrites in place)
  SKIPHDR  if the script sets it non-zero and has no MENUHDR, the built-in menu
           header is skipped once (use when BANNER already prints it).

BUILDING  (strict C89; acpx.c includes plx.c, keep the files together)
  Windows (MinGW-w64)  gcc -O2 -o acpx.exe acpx.c         gcc -O2 -o plxcfg.exe plxcfg.c
  Windows (MSVC)       cl /nologo /O2 acpx.c              cl /nologo /O2 plxcfg.c
  Turbo C / C++ (DOS)  tcc -ml acpx.c                     tcc -ml plxcfg.c   (large or compact model)
  Linux / macOS        cc -ansi -pedantic -o acpx acpx.c  cc -ansi -pedantic -o plxcfg plxcfg.c
  Windows notes: hidden-input fields (H) read keys with _getch() on a real console;
  ANSI escapes (\e[..) are enabled on Windows 10+ consoles at startup.

LIMITS  3000 tokens, 64 variables, 96-char strings, 200000 statements per run.

CHANGES FROM THE DRAFT (all of ACP.PLX draft 1 still runs unmodified)
  + NAME=expr, IF..ELSE, CALL/SUB/VAR blocks, MENUHDR/GOODBYE hooks, H format,
    NAME:fmt output, HALT/EXIT/DELAY/BEEP/PAUSE, hex numbers, escapes (\e for
    ADM-31 escape sequences), comments, system date/time/version variables
  + the password is now checked (ACTPW) and attempts are counted (TRIES/MAXTRY)
  Note: draft 1 puts the 'ACP' AT YOUR SERVICE header inside BANNER; acpx also
  prints it at the first menu, so it appears twice.  Move those two lines to a
  MENUHDR block (see ACP.PLX) or add  ASSIGN INT SKIPHDR.EQ.1.
